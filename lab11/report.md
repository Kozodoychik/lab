# Отчёт
| Номер запуска | Базовый адрес HMODULE (ОЗУ) | Виртуальный адрес функции MessageBoxW |
| ----- | ----- | ----- |
| 1 | 0x7ffc783a0000 | 0x7ffc783fdc70 |
| 2 | 0x7ffc783a0000 | 0x7ffc783fdc70 |
| 3 | 0x7ffc783a0000 | 0x7ffc783fdc70 |
| 4 | 0x7ffc783a0000 | 0x7ffc783fdc70 |

# Ответы
> 1. HMODULE - числовой дескриптор загружаемого модуля. Фактически это начальный адрес виртуальной памяти, по которому библиотека лежит в памяти.
> 2. ASLR - механизм рандомизации расположения программы и модулей в виртуальной памяти. При каждой загрузке библиотеки она отображается в случайный адрес. Не позволяет вредоносному коду использовать фиксированные адреса функций для использования уязвимости.
> 3. Названия функций хранятся строго в виде ASCII-строки. Кодировка Python-строки может автоматически меняться в зависимости от используемых символов.
