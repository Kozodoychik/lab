# Отчёт
> Windows выдаёт ошибку 0xC0000005 (Segmentation fault в Linux) при обращении к невыделенной странице памяти. 
# Ответы
> 1. Обращение к невыделенной памяти вызывает аппаратное исключение, и процесс аварийно завершается.
> 2. MEM_RESERVE лишь резервирует страницы памяти для процесса, а MEM_COMMIT выделяет их физически.
> 3. PAGE_READONLY полезен для хранения данных, чтобы избежать выполнение потенциально вредоносного кода.
