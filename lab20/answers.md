# Ответы
> 1. Windows позволяет открыть устройство без прав администратора тоьлко для чтения метаданных, а для непосредственного чтения или записи требуются права администратора.
> 2. IRP_MJ_DEVICE_CONTROL при DeviceIoControl() и IRP_MJ_CLOSE при CloseHandle().
> 3. При использовании METHOD_BUFFERED ядро выделяет в своей памяти буфер, куда копирует данные из программы перед отправкой в драйвер, так же и в обратную сторону.
