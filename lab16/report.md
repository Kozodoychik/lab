# Отчёт
При использовании высокоуровневых функций Python используется потоковый вывод. Очистка экрана через os.system("cls") не гарантирует того, что видеокарта не увидит промежуточный пустой кадр. WriteConsoleOutputW обеспечивает плавность через буферизацию ввода - вместо того, чтобы постепенно выводить отдельные элементы через print мы подготавливаем готовый кадр в отдельном буфере и подаём его системе.

# Ответы
> 1. 4 байта. Первые два байта используются для символа (UTF-16, ANSI с игнорированием старшего байта), следующие два - аттрибуты (цвет, мерцание и т.д.)
> 2. При двойной буферизации программа подготавливает кадр не напрямую в кадровом буфере, а в отдельном, после чего система настраивает указатели видеокарты на второй буфер (или копирует содержимое бэк-буфера). Такой метод позволяет избежать мерцания, возникаемого вследствие чтения видеокартой кадра во время его построения.
> 3. Использование потокового вывода сильно замедляет работу программы. WriteConsoleOutputW позволяет записывать в терминал уже подготовленный программой буфер.
